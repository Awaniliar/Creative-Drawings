# Creative-Drawings
This is a project i made to be able to create drawings with your mouse and your keyboard.

INSTRUCTIONS:
{Colors}
the main color you start with is black. but you can change it to these colors with these keys:
C = Crimson (red)
V = Violet (purple)
P = Pink
L = Lime (Green)
A = Aqua (Blue)
B = Black (switch back to main color)

{Keyboard Draw)
Arrow key Right = moves your Paintbrush to the right by 20 pixels.
Arrow key Left = moves your Paintbrush to the Left by 20 pixels.
Arrow key Up = moves your Paintbrush Up by 20 pixels.
Arrow key Down = moves your Paintbrush Down by 20 pixels.

{Fill}
to begin filling you must press 'E' BEFORE drawing the shape you want to fill.
to end filling you must press 'R' AFTER you drew your shape.
